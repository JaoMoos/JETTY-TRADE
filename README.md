# JETTY TRADE LIMITED — Official Website

A professional, full-English international trade website for **JETTY TRADE LIMITED**, headquartered in Hong Kong.

## Preview

Open `index.html` directly in your browser, or run a local server:

```bash
# Python
python3 -m http.server 8080

# Node.js (if npx is available)
npx serve .
```

Then visit `http://localhost:8080`.

## Structure

```
GW/
├── index.html          # Main page
├── css/
│   └── styles.css      # Styles & animations
├── js/
│   └── main.js         # Navigation, scroll effects, form
└── README.md
```

## Features

- Fully responsive (desktop, tablet, mobile)
- Smooth scroll navigation with active section highlighting
- Scroll-reveal animations and animated statistics
- Contact form opens the user's email client with pre-filled content
- Premium navy & gold color palette for an international, professional look

## Deployment

Upload all files to any static hosting service:

- **GitHub Pages** — push to a repo and enable Pages
- **Netlify / Vercel** — drag-and-drop or connect the repo
- **Traditional hosting** — upload via FTP to your web server
